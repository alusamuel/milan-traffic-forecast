# Notebooks

- **`notebooks/mobile_traffic_forecasting.ipynb`**: the complete workflow as teaching material. All code is inline and explained step by step: memory-aware loading (two streaming passes), EDA, model design with leakage checks, chronological tuning, final fitting, the nine forecasts and three metric tables, timing, failure analysis, and reloading the saved models to verify them. It does not import `src/`, but mirrors it line for line, so *Run All* writes the same deliverables to `data/processed/`, `results/results/`, `figures/figures/` and `models/models/` as `python run.py all`. It needs the 61 raw files in `data/raw/` and about 30 minutes on a 6-core CPU.
- **`notebooks/inspect_results.ipynb`**: a lightweight viewer for outputs already generated by either route. It does no training.

Use the project's `.venv` as the kernel. `src/milan_forecast/` remains the tested reference implementation.
